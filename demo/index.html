Everything here is one static HTML file with a single script tag pasted before the closing body tag. The round button in the corner is a live voice agent, served by the Arya engine you run.

Click the bubble in the bottom right corner and say hello.

The entire integration

This is the full extent of what a website pastes to get the agent. Build and publish the agent in the Arya builder, copy the snippet from Share & embed, and put it on any page.

<script src="https://YOUR-ENGINE/arya-widget.js"
        data-arya-agent-key="pk_YOUR_KEY" async></script>

One paste

The loader is 3 KB and draws a bubble. The agent itself opens lazily, in its own frame.

Your engine

Audio, provider keys, and transcripts stay on the server you deployed. Nothing here is hosted for you.

Origin locked

The public key only answers on websites you allow, with per-agent caps on calls and duration.

Arya, the open-source voice agent starter kit. This page exists to host the widget. Testing tips: ?key=pk_... uses another agent, ?engine=https://host points at a deployed engine, ?accent=%235a63d6 recolors the bubble.
